# 🎭 Galerie des Conversations

> *Là où les mots deviennent art*

Une expérience artistique interactive qui transforme vos conversations en toiles abstraites uniques.

![Preview](https://via.placeholder.com/800x400/FAFAF9/1C1917?text=Galerie+des+Conversations)

## ✨ Concept

Chaque conversation que vous avez eue avec Claude (ou n'importe qui d'autre) peut être transformée en une **œuvre d'art visuelle** unique. L'algorithme analyse vos échanges et les représente sous forme de lignes, couleurs et formes qui racontent visuellement votre histoire.

### Comment ça marche ?

- **Vos messages** = lignes chaudes (🔴 rouge/or) représentant la passion et l'énergie
- **Réponses de l'assistant** = lignes froides (🔵 bleu/violet) symbolisant la réflexion et le calme
- **Longueur du message** = épaisseur du trait
- **Emojis** = ✨ étoiles brillantes sur la toile
- **Intensité de la conversation** = densité et dynamisme du dessin

## 🎨 Fonctionnalités

### Import facile
- 📄 **Upload fichier** : Importez un .txt contenant votre conversation
- 📋 **Copier-coller** : Collez directement votre conversation

### Visualisation
- 🖼️ **Toiles uniques** : Chaque conversation génère une œuvre d'art différente
- 🎬 **Animation** : Regardez votre conversation se dessiner en temps réel
- 📊 **Métriques** : Voyez l'intensité, le nombre de messages, etc.

### Gestion
- 💾 **Sauvegarde locale** : Toutes vos toiles sont stockées dans le navigateur
- 🗂️ **Filtres** : Triez par intensité (calme, moyenne, intense)
- 💾 **Export** : Téléchargez vos toiles en PNG

## 📋 Format attendu

Pour importer une conversation, utilisez ce format simple :

```
Flow: Salut Léo !
Léo: Hey Flow ! Comment ça va ?
Flow: Super, j'ai un projet à te montrer 🎨
Léo: Avec plaisir ! De quoi s'agit-il ?
```

**Accepte aussi :** `Claude:`, `Assistant:`, `Human:`, `User:`

## 🎯 Algorithme créatif

L'algorithme utilise plusieurs paramètres pour créer une toile unique :

### 1. Analyse du message
- Longueur du texte → Épaisseur du trait
- Détection d'emojis → Étoiles dorées
- Speaker (Flow/Léo) → Palette de couleurs

### 2. Génération visuelle
- Position aléatoire contrôlée (pas de chaos total)
- Angle progressif (création de courbes fluides)
- Gradient de couleurs (chaleur vs froideur)

### 3. Intensité de la conversation
- **Calme** 🧘 : Messages courts, peu d'emojis
- **Moyenne** 💬 : Équilibré
- **Intense** 🔥 : Messages longs, beaucoup d'emojis
